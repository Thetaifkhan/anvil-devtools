Component vs. full URI encoding

Component encoding escapes every reserved character, so it's correct for encoding a single query parameter value. Full URI encoding leaves characters like /, : and ? untouched, so it's correct for encoding an entire URL.

What does "Parse query string" do?

It splits a URL's query string into individual key/value pairs and decodes each one, useful for inspecting a long tracking or API URL.
