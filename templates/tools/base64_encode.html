What is Base64 encoding?

Base64 represents binary data using 64 printable ASCII characters, which makes it safe to embed in text formats like JSON, XML, or URLs (with the URL-safe variant). It is an encoding, not encryption — anyone can decode it.

What's the URL-safe variant?

It replaces + and / with - and _ so the output can be used directly in URLs and filenames without additional escaping.
