How to use the XML Formatter

Paste XML and click Format to pretty-print it with two-space indentation, or tick "Minify" to collapse it onto one line. The formatter first checks the document is well-formed, so malformed XML is reported clearly instead of producing garbled output.

{% endblock %} {% block faq %}

FAQ

Does it validate against a schema?

No — this checks the XML is well-formed (correctly nested, properly closed, valid syntax), not that it matches an XSD or DTD schema.
