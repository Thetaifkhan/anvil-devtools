What this checks

The validator confirms your XML is well-formed: every tag is properly closed and nested, attribute values are quoted, and there's exactly one root element. It reports the line and column of the first problem it finds.

FAQ

What's the difference between "well-formed" and "valid" XML?

Well-formed means the syntax is correct. Valid means it also conforms to a schema (DTD/XSD) — this tool checks well-formedness only.
