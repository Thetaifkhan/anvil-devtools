How this SQL formatter works

This tool uses a real tokenizing SQL parser (not regex string manipulation) to reindent queries and normalize keyword casing. It does not fully validate every vendor-specific SQL dialect — for dialect-specific syntax checking, use your database's own linter.

FAQ

Does this support every SQL dialect?

Formatting works well across standard ANSI SQL and most vendor dialects (PostgreSQL, MySQL, SQL Server), but highly dialect-specific syntax may not reformat perfectly.
