What makes a password strong?

Length matters more than complexity rules: a random 20-character password from a large character set is far stronger than a short one with forced symbols. This tool uses crypto.getRandomValues for cryptographically secure randomness.

Is this stored anywhere?

No — the password is generated in memory in your browser and is never transmitted or logged. Use a password manager to store it securely.
