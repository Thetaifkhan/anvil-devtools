How to use the JSON Formatter

Paste or drag a .json file into the input panel, choose an indent width, then click Format to pretty-print it, or Minify to collapse it onto one line. Enable Sort keys to alphabetize object keys, which is useful when diffing two JSON files that only differ in key order.

Example

{"name":"John","age":30,"skills":["Python","JavaScript"]}

becomes:

{
  "name": "John",
  "age": 30,
  "skills": [
    "Python",
    "JavaScript"
  ]
}

Common errors

The formatter reports the exact line and column where parsing failed — for example a trailing comma, an unquoted key, or a missing closing brace — instead of a generic "invalid JSON" message.

FAQ

Does this tool send my JSON to a server?

No. Formatting and minifying both run entirely in your browser using JSON.parse and JSON.stringify. Nothing is uploaded.

Is there a size limit?

The tool works well into the tens of megabytes, limited only by your browser's memory. Very large files may take a moment to render.

Can I format JSON with comments?

Standard JSON doesn't support comments. If your input has them (JSONC), remove the comments first or the parser will report an error at that location.
