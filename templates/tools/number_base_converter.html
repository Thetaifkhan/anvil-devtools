Number bases explained

Binary (base 2) and hexadecimal (base 16) are the two bases developers touch daily — binary for bitwise logic and flags, hex for memory addresses, colors, and byte-level data. Octal (base 8) is less common today but still appears in Unix file permissions.

FAQ

Does this support negative numbers?

No — this converts non-negative integers. For signed/two's-complement representations, the bit width matters and should be handled explicitly in your own code.
