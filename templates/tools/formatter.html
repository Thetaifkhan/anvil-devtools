One workspace, every data format

The Formatter replaces jumping between separate pages for each language: pick a format from the tabs above, paste your content, and beautify, minify or validate it in place. JSON and Markdown run entirely client-side; XML, YAML and SQL are formatted on the server using real parsers so results stay accurate, and nothing you send is logged or stored.

Formats still being added

JavaScript, HTML and CSS formatting need a safe, dependency-light beautifier before we turn them on — rather than guess, the UI tells you plainly that they're not ready yet instead of silently producing incorrect output.

FAQ

Does switching formats lose my input?

Yes — each format expects different content, so the input and output clear when you switch tabs. Copy or download first if you need to keep it.

Is there a keyboard shortcut?

⌘/Ctrl + Enter runs the primary action (Format) for the active tab.
