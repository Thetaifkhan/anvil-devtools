How JSON validation works

This tool parses your input with the browser's built-in JSON parser and reports the exact failure point rather than a generic error. You'll get a line number, column number, and a plain-English explanation such as "expected ',' or '}' after property value."

FAQ

Why does it say "Unexpected token" without more detail?

That message comes directly from the JSON parser. Anvil adds the line/column location on top of it so you can find the exact spot.

Does trailing-comma JSON validate?

No — standard JSON forbids trailing commas. Remove the comma after the last item in an object or array.
