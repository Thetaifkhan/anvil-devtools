How XML diff works

This tool compares two XML documents structurally, showing added, removed, and modified elements and attributes. It handles namespaces, attributes, and text content while optionally ignoring whitespace differences.

{% endblock %} {% block faq %}

FAQ

Does it handle namespaces?

Yes, namespace URIs are compared. Prefix changes are shown as structural differences (which is technically correct XML semantics).

What about text content?

Text nodes are compared character-by-character. Leading/trailing whitespace can be ignored with the whitespace checkbox.
