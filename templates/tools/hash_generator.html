Which hash should I use?

SHA-256 is the standard general-purpose choice today. MD5 and SHA-1 are included because legacy systems still require them for checksums, but both are cryptographically broken and unsuitable for security purposes such as password storage or signatures.

FAQ

Should I use this to hash passwords?

No. Password storage requires a dedicated slow hash like bcrypt, scrypt, or Argon2 with per-user salting — general-purpose hashes like SHA-256 are too fast and unsalted, making them unsuitable for that job.
