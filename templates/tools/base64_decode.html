How this works

Handles both standard and URL-safe Base64 automatically, and tolerates missing padding = characters. If the decoded bytes aren't valid UTF-8 text, a download link is offered instead of garbled text.

FAQ

Why do I get an error decoding?

The most common cause is input that isn't actually Base64 — for example accidentally pasting a JWT (three dot-separated segments) instead of a single Base64 string.
