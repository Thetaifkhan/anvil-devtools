How to use the JSON Tree Viewer

Paste JSON and click Render to explore it as a collapsible tree. Click any triangle to expand or collapse a node, or use the search box to highlight matching keys and values. Click a value to copy it, or click a key to copy its JSONPath (e.g. $.user.skills[0]).

FAQ

What is JSONPath?

JSONPath is a query syntax for addressing a value inside a JSON document, similar to XPath for XML. Copying a node's path gives you a ready-to-use expression like $.user.address.city.
