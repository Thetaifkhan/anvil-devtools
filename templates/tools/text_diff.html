How the text diff works

This uses a line-based longest-common-subsequence algorithm — the same family of algorithm used by diff and Git — to find the minimal set of added and removed lines between the two inputs.

FAQ

Does it diff word-by-word?

No, this compares line by line. For very long single-line texts, break them into shorter lines first for a more useful diff.
