What is a JWT?

A JSON Web Token has three dot-separated, Base64url-encoded parts: a header describing the signing algorithm, a payload of claims, and a signature. This tool decodes the header and payload so you can inspect them — it deliberately does not attempt signature verification, since that would require handling a secret or key.

Standard claims explained

  • iat — issued-at time
  • exp — expiration time
  • nbf — not valid before this time
  • iss — issuer
  • aud — intended audience
  • sub — subject (usually the user ID)

FAQ

Is a decoded JWT trustworthy?

No. Decoding only reveals the claims — it does not confirm they were issued by a legitimate server or haven't been tampered with. Only signature verification, done server-side with the correct key, confirms authenticity.

Should I paste a production token here?

Avoid pasting tokens containing sensitive production data into any third-party tool. This page processes everything locally and sends nothing to a server, but good practice is to use test tokens where possible.
