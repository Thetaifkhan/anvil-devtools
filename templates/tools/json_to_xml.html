How JSON to XML conversion works

JSON objects become nested XML elements, arrays become repeated <item> elements, and primitive values become element text content. Keys that aren't valid XML tag names (starting with a digit, containing spaces) are automatically sanitized.

Limitations

JSON and XML don't share a data model: XML has no native concept of arrays or of a `null` vs. missing distinction, and it separates attributes from element content in ways JSON does not. This converter uses simple, predictable conventions rather than trying to guess your intended schema — for full control over attributes, hand-edit the output afterward.

FAQ

How are JSON arrays represented in XML?

Each array item becomes a sibling <item> element under its parent, since XML has no native array type.
