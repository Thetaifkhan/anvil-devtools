How it works

Input must be an array of objects (or a single object, treated as a one-row array). Column headers are collected from every key seen across all rows, in first-seen order.

FAQ

What happens with nested objects?

CSV is inherently flat. Nested objects or arrays inside a row are ignored for that column — flatten your data first if you need those values as columns.
