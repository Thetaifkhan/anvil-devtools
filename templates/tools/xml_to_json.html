How XML to JSON conversion works

Element attributes are placed under an @attributes key, repeated child elements become JSON arrays, and elements with only text content collapse to a plain string value. This keeps the output predictable rather than trying to infer types.

Limitations

XML namespaces, processing instructions, and mixed text/element content don't map cleanly to JSON. Namespace prefixes are preserved as part of the tag name where present, but namespace resolution is not performed.

FAQ

Where do XML attributes go?

Under an @attributes object on the corresponding JSON node, so they never collide with real child element names.
