How do I get an access token?

The fastest path is to sign into your Supabase project dashboard, open the SQL editor or Auth → Users, and use the Get user token feature for a real admin user. Production deployments should replace this paste-token form with a real OAuth redirect.

The token is sent only to /admin/login on this server, verified against the Supabase auth API, then discarded — it is never written to disk or shipped to the browser after verification.
